What the Google connection does

  • Reads Google Calendar lists and event details for personal scheduling summaries.
  • Reads limited Gmail message metadata to support personal organisation and triage.

Where information goes

Google information is processed for the account owner's own use on devices they control. This public website contains no account data, stored messages, calendar events, access tokens, or server endpoints.
